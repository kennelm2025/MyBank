\# MyBank · Vendor Evaluation Simulator



Interactive evaluation simulator for MyBank's core platform replacement

programme, comparing three anonymised vendor options — CAKE, BinB and DIY —

across five weighted dimensions.



\*\*Live:\*\* https://kennelm2025.github.io/MyBank/



\## What it does

\- Scores each vendor on D1 Functional Fit (35%), D2 Technology \& Architecture

&#x20; (25%), D3 Implementation \& Delivery (20%), D4 Operational (10%), D5 Risk \&

&#x20; Vendor (10%).

\- SME validation scores (1–4) are the authoritative headline metric; the

&#x20; vendor's own claim is shown alongside.

\- Headline = Weighted SME Score = Σ(dimension SME × strategic weight).

\- L1 views: Executive Summary, SME Slider Scores, Dimension Drill-Down, Score

&#x20; Card, Claimed vs Validated, SME Divergence, Discrepancy Map, Build vs Buy,

&#x20; Critical Functions, TCO Comparison, Risk Heatmap, Red-Zone Domains.

\- L2 Strategic Analysis layer with seat-based strategic weighting.

\- Import completed vendor workbooks (CAKE / BinB / DIY) to load real evidence;

&#x20; imported evidence is immutable and overrides the embedded baseline.



\## Use

Open `index.html` directly, or use the GitHub Pages URL above. Single
